## 这是什么

**第五人格**的世界里，欧利蒂丝庄园充满了谜团、背叛与谋杀——医生的手术刀、律师的谎言、慈善家的孤儿院、园丁丢失的记忆、佣兵的危险直觉。每个角色都背负着黑暗的过去。

这个项目让 AI 利用第五人格角色的**真实背景故事和关系网**，在每局游戏开始时**程序化生成一份完全不同的谋杀谜题**。医生可能是死者，律师可能是凶手，也可能完全反过来——取决于 AI 本局的创作。

你的任务：扮演收到庄园邀请函的调查者，探索庄园、与角色交谈、收集线索、戳破谎言，最终**指出真凶**。

**对第五人格玩家来说：这是你从未体验过的庄园故事。**
**对没玩过第五人格的人来说：这是一场硬核 AI 推理游戏。**

## 核心卖点

### 🎭 第五人格 IP — 真实角色，全新命案

游戏中的 5 名角色全部来自第五人格官方设定，拥有真实的背景故事：

| 角色 | 身份 | 你将在游戏中看到的 |
|------|------|-------------------|
| 艾米丽·黛儿 | 医生 | 手术台上的秘密、白沙街孤儿院的电击治疗 |
| 艾玛·伍兹 | 园丁 | 被遗忘的童年、对"故人"的执念 |
| 克利切·皮尔森 | 慈善家 | 孤儿院面具下的罪恶 |
| 弗雷迪·莱利 | 律师 | 背叛挚友的过去 |
| 奈布·萨贝达 | 佣兵 | 战场上的生死抉择 |

**角色之间的关系网（仇敌、利益、背叛）成为 AI 生成谋杀动机的素材。**

如果你了解第五人格剧情，你会在游戏中发现大量彩蛋。如果你不了解——游戏本身就是最好的入坑方式。

### 🤖 AI 程序化谜题 — 每局都是全新案件

```
5个第五人格角色 + 官方关系网
        ↓ AI 生成（开局一次，约30秒）
一份完整谋杀剧本：
  ✓ 死者是谁
  ✓ 真凶是谁（动机基于第五人格角色关系）
  ✓ 作案手法和时间线
  ✓ 线索分布在庄园各处
  ✓ 每个 NPC 的证词（真相 + 隐瞒 + 谎言）
  ✓ 剧情反转
```

**你玩的每一局，凶手、动机、线索都可能不同。** 上次律师是凶手，这次园丁可能是受害者，下次佣兵可能被陷害。

### 🧠 分层记忆 — 不怕 AI 忘了剧情

| 层级 | 内容 | 作用 |
|------|------|------|
| 近期对话 | 最近 N 轮完整文本 | AI 知道刚才发生了什么 |
| 剧情摘要 | 早期剧情的 AI 压缩 | AI 记得之前的调查进展 |
| 关键线索 | 玩家已发现的物证/证词 | AI 不会忘记你找到的线索 |

这让 AI 能在长线推理中保持剧情一致性，不会前后矛盾。

### 🎯 明确目标 — 找到真凶

不是模糊的"探索庄园"——你的目标很明确：**收集证据，指认真凶**。错误的指控会让真凶逃脱，正确的指控让真相大白。

## 游戏流程

```
开局 → 案发 → 自由探索 → 收集线索 → 指认真凶 → 真相大白 / 冤案
```

不需要记步数、不需要管理智值。**你什么时候觉得推理够了，就什么时候指认。**

## 技术架构

```
AI-Manor-Game/
├── app.py                       # Streamlit 主程序
├── engine/
│   ├── mystery_generator.py     # AI 谜题剧本生成（基于角色关系网）
│   ├── narrator.py              # AI 主持人叙事引擎（驱动剧情）
│   └── memory.py                # 分层记忆系统
├── characters.json              # 第五人格角色数据 + 关系网
├── world.txt                    # 欧利蒂丝庄园氛围 + 规则
├── map.txt                      # 庄园地点
├── requirements.txt
└── .env.example
```

### 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | Streamlit（Chat UI） |
| AI | DeepSeek API（deepseek-chat） |
| 状态管理 | streamlit.session_state |
| 数据 | JSON（角色）+ TXT（世界/地图） |
| 配置 | python-dotenv |

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置 DeepSeek API Key
cp .env.example .env
# 编辑 .env → DEEPSEEK_API_KEY=你的key

# 3. 启动
streamlit run app.py
```

浏览器访问 `http://localhost:8501`

开局后 AI 会花约 30 秒生成谜题，然后游戏开始。
